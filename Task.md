# Список заданий

## Одно событие

Формализуйте утверждения в предположении, что говорящая сейчас не замужем и никогда замужем не была. Используйте атомарный предикат p, обозначающий событие "я выхожу замуж" (книга [5], задание 2.13). Считать, что p истинно только в момент выхода замуж (в один дискретный момент времени), а не все время в браке. Считать, что p может быть истинно в соседние моменты времени, это считается двумя отдельными “выходами замуж”.

1. Я выйду замуж не менее двух раз.

   ```text
   <> ( q && X <> q )
   ```

2. Я выйду замуж не более двух раз.

   ```text
   [] (p -> X [] (p -> X [] !p))
   ```

   ```text
   !(<> (p && X <> (p && X <> p)))
   ```

3. Я выйду замуж точно два раза.

   ```text
   !p U (p && X (!p U (p && X [] !p)))
   ```

4. Я выйду замуж не менее одного раза.

   ```text
   <> q
   ```

5. Я выйду замуж не более одного раза.

   ```text
   [] (p -> X [] !p)
   ```

6. Я выйду замуж точно один раз.

   ```text
   !p U (p && X [] !p)
   ```

7. Я никогда не выйду замуж.

   ```text
   [] !p
   ```

## Два события
Формализуйте утверждения с двумя атомарными предикатами a и b:

1. Событие a может случиться только во время b.

   ```text
   [] (a -> b)
   ```

2. Событие a обязательно случится, но только во время b.

   ```text
   (<> a) && [] (a -> b)
   ```

3. Событие a обязательно случится, но это произойдет после того как какое-то время будет истинно b, при этом b должно обязательно произойти.

   ```text
   <> (b && X (b U a))
   ```

## Одно событие. Самостоятельно
Придумайте 5 выражений, которые можно формализовать с помощью утверждений LTL с одним атомарным предикатом a. Формализуйте их.

1. После каждого наступления события a в следующий момент событие a обязательно должно быть ложно.

   ```text
   [] (a -> X !a)
   ```

2. Когда-нибудь должна встретиться последовательность: a, затем не a, затем снова a.

   ```text
   <> (a && X (!a && X a))
   ```

3. С некоторого момента значение события a должно строго чередоваться.

   ```text
   <> [] ((a -> X !a) && (!a -> X a))
   ```

4. Событие a произойдёт хотя бы один раз, но с некоторого момента больше никогда происходить не будет

   ```text
   (<> a) && (<> [] !a)
   ```

5. С некоторого момента значение a стабилизируется и больше не будет изменяться.

   ```text
   <> ([] a || [] !a)
   ```

## Два события. Самостоятельно
Придумайте 5 выражений, которые можно формализовать с помощью утверждений LTL с двумя атомарными предикатами a и b. Формализуйте их.

1. Если a и b произошли одновременно, то в следующий момент оба должны быть ложны.

   ```text
   [] ((a && b) -> X (!a && !b))
   ```

2. После каждого a предикат b должен быть истинным до следующего a, причём следующее a обязательно должно наступить.

   ```text
   [] (a -> X (b U a))
   ```

3. Когда-нибудь должна встретиться последовательность: только a, затем только b, затем снова только a.

   ```text
   <> ( (a && !b) && X ( (b && !a) && X (a && !b) ) )
   ```

4. С некоторого момента события a и b всегда должны иметь противоположные значения.

   ```text
   <> [] ((a && !b) || (!a && b))
   ```

5. Если событие a произошло два момента подряд, то ещё через один момент обязательно произойдёт b.

   ```text
   [] ((a && X a) -> X X b)
   ```
